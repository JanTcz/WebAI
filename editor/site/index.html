WebAI Editor, right in your browser

Click the page. Say what to change.

Hold Shift and click any element on this page. A chat opens with an AI agent that knows the exact spot in the source code and edits it right away.

How it works

How it works

  1. Pick an element

    Shift+click a heading, a button or a paragraph. To chat without a selection, use the ✦ button.

  2. Say what you want

    For example “shorter heading”, “make the button green” or “add a third card about pricing”.

  3. Watch it change

    The agent edits the files and the page reloads by itself. See the code via “Source” at the top.

Features

  • The exact spot

    Every element carries its file, line and column. The agent doesn't guess where things are.

  • One conversation

    It builds on previous messages, so “a little smaller still” just works.

  • In your project too

    In Astro, as an integration for astro dev with Claude Code, Codex, OpenCode or Pi.
